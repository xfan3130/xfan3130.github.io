# Total Recall

A free-for-all memory showdown for 2–6 players (about 45 minutes), built for the AP Psychology board game project. Each round makes players **experience** a Unit 2 (Cognition) memory concept, then reveals what happened with a chart of the group's own results.

| Page | What it is |
|---|---|
| `index.html` | The game: flash cards, timers, buzzers, scoreboard, "GOTCHA!" reveals |
| `rules.html` | Printable rules, sample of play, and the player recall sheet |
| `psych.html` | One-page explanation of the psychology terms (prints on 1 page, for Canvas) |

## Rounds
1. **The List**: serial position effect (primacy and recency)
2. **Strings**: working memory span (7 ± 2) and chunking
3. **Snap Judgments**: levels of processing and the self-reference effect
4. **Memory Check**: false memory (DRM), spreading activation and source amnesia
5. **Recall Bowl** (buzzer round): recall vs. recognition, retrieval cues and interference

Two decks (A and B) let groups replay with fresh lists.
